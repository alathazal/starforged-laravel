# alathazal/starforged-laravel

![Static Badge](https://img.shields.io/badge/version-0.1.0-blue)
![Static Badge](https://img.shields.io/badge/php-8.4-green?logo=php)
![Static Badge](https://img.shields.io/badge/pest-5.1-green)

The **starforged-laravel** package is a laravel specific component that provides a Laravel style service provider for
the [alathazal/starforged-php](https://github.com/alathazal/starforged-php) / [alathazal/starforged-data](https://github.com/alathazal/starforged-data)
packages, to provider strucutred access to the data they supply.
